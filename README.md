# TheStrangeWild

Roguelike wild-themed game write with [Godot](https://godotengine.org/)


## Where to play

**[Play TheStrangeWild in your browser](https://trion17fft.itch.io/thestrangewild)** — have fun !!

![Ur Logo](Title.png)


## Controls

| Action       | Key(s)              |
| ------------ | --------------------|
| Move         | Arrow keys / WASD   |
| attack         | right click               |
| BACK    | escape    |

## Features

- Severals enemies
- A boss and more Soon
- The game is inspired by the Universe of Cult Of The Lamb
- Playable on your browser
